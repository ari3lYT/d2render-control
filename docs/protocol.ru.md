# Протокол очереди

Все пути считаются от корня очереди. ID соответствует `[a-zA-Z0-9_-]{8,80}`. Запросы — JSON в UTF-8.

| Путь | Кто пишет | Значение |
| --- | --- | --- |
| `inbox/ID.json` | Мод | Полностью опубликованный запрос |
| `inbox/ID.pending` | Мод | Незавершённая запись; обработчик должен её игнорировать |
| `cancel/ID` | Мод | Запрошена отмена; обработчик выбирает ближайшую безопасную границу |
| `results/ID.json` | Обработчик | Результат с конечной или промежуточной стадией `stage` |
| `status.json` | Обработчик | `updated`, необязательные `active` и массив `recent` |

Варианты запросов:

```json
{"kind":"area","a":[-32,80,-32],"b":[32,80,32],"requested_by":"DemoOperator"}
```

```json
{"kind":"camera","camera":[0,100,0],"target":[32,70,32],"requested_by":"DemoOperator"}
```

```json
{"kind":"video","camera":[0,100,0],"end":[64,100,0],"target":[32,70,32],"seconds":4,"requested_by":"DemoOperator"}
```

Конечные стадии результата: `success`, `cancelled` или `error`. Отображаемые поля: `id`, `stage`, `frame`, `frames`, `spp`, `url` и `error`. Публикуйте статусы и результаты атомарно. Настоящий рендер может получить статус успеха только после надёжного сохранения результата. Отмена носит рекомендательный характер; мод не завершает процессы обработчика принудительно. `tools/mock_worker.py` записывает явную ошибку о том, что медиа не создаются: он проверяет только соединение компонентов. Запрос содержит отображаемое имя автора команды; содержимое рабочей очереди должно оставаться приватным.
