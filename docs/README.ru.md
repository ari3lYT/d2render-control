# D2 Render Control

Серверный Fabric-мод отправляет ограниченные запросы рендера в файловую очередь и показывает
статус отдельного рабочего процесса. Сам рендерер в мод не входит. Сборка: `./gradlew build`.

Установи на тестовый Minecraft 26.3 / Java 25, подключи Fabric API и проверь `/render status`.
Для своей реализации рабочего процесса используй `docs/protocol.md`. Тестовый mock-worker
проверяет обмен файлами, но не создаёт изображения и не доказывает работу настоящего рендера.
