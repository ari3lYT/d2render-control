# Настройка

Системное свойство JVM `d2render.queue` задаёт корень очереди. По умолчанию: `config/d2gate/render-queue`. Имя каталога сохранено для совместимости с существующими установками; D2Gate при этом не требуется.

Право записи предоставляйте только доверенным локальным сервисам. При необходимости подключите каталог очереди внешнему обработчику, предоставив лишь нужный доступ; не открывайте ему произвольный доступ к настройкам и секретам сервера. Мод управления не устанавливает рендерер, не управляет питанием NAS, не реализует каналы доставки или веб-сервис. Интегратор реализует их отдельно по [протоколу очереди](protocol.ru.md).
